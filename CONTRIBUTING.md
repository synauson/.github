# Contributing

Synauson publishes the source of its client libraries and examples so you can read,
build and use them under their licenses. Development happens inside Synauson, and these
repositories don't accept outside contributions: pull requests from outside Synauson
are closed without review.

To report a bug, request a feature or ask a question, contact Synauson through
[synauson.com](https://synauson.com).
